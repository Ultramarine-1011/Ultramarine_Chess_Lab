操作与规则

点击棋子再点击目标格，或拖动落子。圆点表示合法目标格；升变可选择后、车、象、马。悔棋退回你的上一个回合。

将死、逼和、子力不足自动结束。满足五十步或三次重复申和条件时（包括下一步可申和）自动判和。没有整局时钟。

也可以在下方输入 UCI 着法，使用键盘完成落子。
